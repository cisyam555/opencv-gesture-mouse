# OpenCV 文档扫描预处理工具（OCR 前置）

将手机拍摄的平面纸张照片转成透视矫正、光照归一化的扫描图片。支持自动检测和手动指定四角。

## 安装和运行

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python document_scanner.py 文档照片.jpg -o output
```

中文路径可以直接使用。默认自动检测；自动识别失败会提示手动方式，不会把整张照片冒充检测成功。

```bash
# 桌面窗口：点击纸张四角，Enter 确认，R 重选，Esc 取消
python document_scanner.py 文档照片.jpg --manual

# 无 GUI 环境：传入原图像素坐标，顺序不限
python document_scanner.py 文档照片.jpg --points "120,80;960,130;900,1400;60,1320"

# 调整二值化参数
python document_scanner.py 文档照片.jpg --block-size 51 --threshold-c 10
```

鼠标选点应选择纸张真正的四角。点击后还未确认时可按 R 重选；若自动选角不准，检查结果后用 `--manual` 重新运行。手动窗口需要桌面环境及 `opencv-python`，不要同时安装 `opencv-python-headless`。

## 流程与实现

1. **找边缘**：将检测用图缩至最长边 1400 像素，灰度化、5×5 高斯模糊、Canny（50/150）、闭运算连接断边。
2. **找四边形**：对边缘图和 Otsu 亮纸张掩膜找轮廓，用 `approxPolyDP` 多种精度逼近；筛选面积至少占照片 15% 的凸四边形，排除照片整体边框，选择面积最大的候选。
3. **矫正**：对四点按角度排序，再还原到原图坐标；取对边长度最大值确定输出宽高，通过 `getPerspectiveTransform` 和 `warpPerspective` 矫正。
4. **去阴影**：灰度图膨胀抑制文字，再模糊估计背景光照，采用 `灰度 / 背景 × 255` 做亮度归一化。
5. **二值化**：中值滤波降噪，使用高斯自适应阈值产生黑字白底图。

检测只使用缩小图，透视变换使用原图，避免把低分辨率预览当作最终扫描件。输出大小由原图中的文档边长估算；不会凭空恢复失焦、过曝或缺失的细节，也不自动推断物理纸张尺寸和 DPI。

## 输出

| 文件 | 用途 |
| --- | --- |
| `edges.png` | 缩小后的边缘图，排查检测问题 |
| `detected.png` | 原图上叠加绿色四边形，检查是否误选 |
| `color.png` | 保留颜色的原图透视矫正结果 |
| `gray.png` | 去阴影、降噪的灰度图 |
| `scan.png` | 适合打印或 OCR 的黑白二值图 |

输出固定文件名，重复运行同一输出目录会覆盖之前的结果。不同文档请使用不同的 `-o` 目录。

## 效果边界与调参

- 推荐纸张完整入镜，与背景颜色有明显区别。桌面上的书本、屏幕或相框也可能成为最大四边形，因此必须检查 `detected.png`。
- 低对比度、强阴影、复杂背景、小于照片面积 15% 的纸张可能漏检，使用手动模式。
- 平面透视只能矫正平面纸张，不能展平弯曲书页，也不能判断文字是否上下颠倒。菱形或大角度旋转的文档可能需要后续旋转。
- 强硬阴影、彩色底纹、大图片和反光可能影响光照估计。OCR 可分别尝试 `gray.png` 和 `scan.png`，二值化不保证总是更好。
- 文字断裂或细字丢失时可适当减小 `--threshold-c`；噪点过多可增大它。邻域大小应结合字大小调整。

## 可选 OCR

另行安装 Tesseract 及简体中文语言包后执行（本工具本身不依赖 OCR）：

```bash
tesseract output/scan.png output/text -l chi_sim+eng --psm 3
```

输出为 `output/text.txt`。`--psm 3` 适合一般页面；单一文字块可以尝试 `--psm 6`。批量扩展时遍历输入文件，并为每张图创建单独输出目录即可。

## 验证

```bash
python -m unittest discover -s tests -v
```

测试使用合成倾斜纸张检查检测精度、原始分辨率透视矫正、光照归一化和完整命令行输出；真实手机照片与交互窗口仍需实际验证。
