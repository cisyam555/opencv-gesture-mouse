# 基于 OpenCV 与 MediaPipe 的手势虚拟鼠标

使用摄像头识别手部关键点，通过食指位置控制电脑指针，通过拇指与中指、食指的短捏合完成左右键单击。当前是学习与演示阶段版本，重点实现指针平滑、点击判断和误触抑制。

## 当前功能

- 摄像头实时预览、镜像显示和 21 个手部关键点绘制。
- 食指指尖映射到屏幕，画面中央 70% 为有效操作区域。
- 指针指数平滑，减少关键点抖动。
- 拇指与中指短捏合后松开：左键单击。
- 拇指与食指短捏合后松开：右键单击。
- 捏合期间锁住指针，减少点击位置偏移。
- 默认暂停，键盘切换启停；手离开画面后停止移动并取消待触发点击。
- 模拟距离序列测试，不操作真实鼠标。

尚未实现：拖动、专用双击、滚动、握拳暂停、张手恢复、截图、软件启动面板。当前检测到手就会根据食指位置移动，不限制为“仅食指伸直”的姿态。

## 技术栈与职责

| 技术 | 用途 |
| --- | --- |
| Python | 交互逻辑与程序组织 |
| OpenCV | 摄像头采集、镜像、坐标可视化、窗口显示 |
| MediaPipe HandLandmarker | 检测并跟踪手部 21 个关键点 |
| NumPy | 距离计算、坐标映射 |
| PyAutoGUI | 获取屏幕尺寸、移动指针、执行左右键点击 |

## 环境要求

当前开发环境为 Linux X11、Python 3.12。需要可用的摄像头和图形桌面会话；Wayland、远程无桌面环境和多显示器操作尚未验证。摄像头处理在本地进行，程序没有录制或上传画面的功能。

## 安装

```bash
git clone git@github.com:cisyam555/opencv-gesture-mouse.git
cd opencv-gesture-mouse/opencv
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Ubuntu/Debian 如果无法创建环境，可先安装 `python3-venv`。OpenCV 的几个发行包共用 `cv2` 名称，新环境只安装本项目声明的 `opencv-contrib-python`，不要再同时安装 `opencv-python` 或 headless 版本。

### 下载模型

在 `opencv/` 目录执行：

```bash
mkdir -p models
curl -L --fail "https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task" -o models/hand_landmarker.task
```

模型由 MediaPipe 官方提供，单独下载，不随仓库提交。程序按 `main.py` 所在位置寻找模型。

## 运行与手势

在 `opencv/` 目录、虚拟环境激活后运行：

```bash
python main.py
```

| 操作 | 手势或按键 |
| --- | --- |
| 启动/暂停 | 选中摄像头窗口，按英文小写 `s` |
| 移动鼠标 | 移动食指，拇指与食指、中指保持分开 |
| 左键单击 | 拇指与中指短捏合，再充分松开；食指远离拇指 |
| 右键单击 | 拇指与食指短捏合，再充分松开；中指远离拇指 |
| 退出 | 选中摄像头窗口，按 `q` 或 `Esc`；终端可按 `Ctrl+C` |

口诀：**中指左击，食指右击，松开生效。**

蓝框表示操作区域。默认显示 `PAUSED`，按 `s` 后变为 `ACTIVE`。点击成功时画面显示 `LEFT CLICK` 或 `RIGHT CLICK`。鼠标点击其他窗口后，快捷键不一定送到摄像头窗口；需要重新选中窗口，或在运行终端中停止程序。PyAutoGUI 的屏幕角落安全保护保持开启。

## 实现原理

1. OpenCV 读取并镜像画面，将 BGR 转换成 RGB。
2. MediaPipe 以 VIDEO 模式处理递增时间戳的帧，返回手部关键点。
3. 食指指尖（8 号点）映射到屏幕坐标，用 `当前位置 += (目标位置 - 当前位置) × 0.25` 平滑移动。
4. 计算拇指（4 号点）到中指（12 号点）和食指（8 号点）的距离，分别除以手掌宽度（5 到 17 号点的距离）。
5. 独立判断器跟踪准备、捏合、松开和冷却过程。仅当动作有效时，调用 `pyautogui.click`。

### 防误触参数

参数位于 `opencv/gestures.py`，时间单位为秒，距离为相对手掌宽度的比例。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `PINCH_ENTER` | 0.25 | 距离低于此值进入捏合 |
| `PINCH_EXIT` | 0.40 | 距离高于此值视为松开，形成阈值缓冲 |
| `MIN_HOLD` | 0.08 | 忽略过短捏合 |
| `MAX_HOLD` | 0.60 | 长捏取消点击，当前不触发拖动 |
| `RELEASE_TIME` | 0.06 | 松开需保持稳定后才点击 |
| `READY_TIME` | 0.15 | 充分分开后才能接受新动作 |
| `COOLDOWN` | 0.25 | 两次点击的最小间隔 |
| `MAX_FRAME_GAP` | 0.25 | 数据中断过久时取消待触发动作 |

两种捏合同时出现时取消判断；手部消失时重置状态；手掌投影宽度不足 20 像素时暂停操作。侧掌、遮挡和光照变化仍可能造成误判，参数需要结合实际测试调整。

## 测试与展示

在 `opencv/` 目录执行：

```bash
python -m unittest test_gestures -v
```

当前 8 项模拟测试覆盖左右击、松开后不重复点击、长捏取消、短时抖动、双重捏合冲突、跟踪丢失、帧中断和初始捏合不触发。测试验证状态判断，不代表真实摄像头识别准确率。

现场验证建议：

1. 暂停状态移动手，确认指针不跟随。
2. 启动控制，将食指移动到蓝框四周，观察屏幕映射与抖动。
3. 在空文件夹内左击选中文件、右击弹出菜单，核对对应关系。
4. 捏合保持超过 0.6 秒再松开，确认没有点击。
5. 捏合期间将手移出画面，再移回，确认没有补发点击。
6. 记录实际点击成功次数、误触次数和使用距离，作为后续调参依据。

语法与导入已检查，8 项模拟测试通过；真实相机体验需在使用者的桌面环境验证，尚无量化识别准确率结论。
